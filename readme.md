1. Просмотр и добавление треков:
Вывод списка треков на главной странице (/). Просмотр подробной информации об отдельном треке (/tracks/<id>).
Добавление новых треков (/tracks/add).

2. Редактирование объектов :
Маршрут /tracks/<id>/edit для изменения существующих записей. Предзаполнение формы текущими данными трека, валидация при отправке и сохранение введённых значений в случае ошибки.

3. Дополнительные функции:
Поиск (`request.args`): поиск треков по названию или исполнителю на главной странице. Фильтрация: возможность отфильтровать только избранные треки («Любимые ⭐️»). Удаление (`POST`): удаление трека со страницы подробностей через POST-запрос (/tracks/<id>/delete).
